# Фаза 0 — журнал

Одностраничный журнал тренировок. Работает офлайн, ставится на главный экран телефона.

## Установка на GitHub Pages

1. **Новый репозиторий.** GitHub → New repository. Имя: `faza0`. Видимость: Public.
   Код внутри публичный, но записи журнала в него не попадают — они остаются на телефоне.
2. **Загрузить файлы.** В пустом репозитории: *uploading an existing file* → перетащить
   все файлы из этой папки → Commit changes.
3. **Включить Pages.** Settings → Pages → Source: *Deploy from a branch* →
   Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты адрес будет: `https://ИМЯ.github.io/faza0/`

## На телефон

Открыть адрес в Chrome → меню (три точки) → **Добавить на главный экран**.
Появится иконка, запуск на весь экран, работа без интернета.

## Обновление

При замене `index.html` открой `sw.js` и поменяй `VERSION` (`faza0-v1` → `faza0-v2`),
иначе телефон продолжит показывать старую копию из кэша.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | вся программа и журнал |
| `manifest.webmanifest` | имя, иконка, полноэкранный режим |
| `sw.js` | офлайн-кэш |
| `icon-*.png` | иконки |
